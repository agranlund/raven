# Opensource MacOS/Linux workflow for CUPL + device programming

## 5vcomp
wrapper for WinCUPL, using Wine.
See link for setup instructions.
- Original: https://github.com/peterzieba/5Vpld

## fuseconv
converts JED -> SVF for flashing with open source utilities (open-ocd etc)
- Original: https://github.com/ole00/afterburner/tree/master/utils/jtag
- Original: https://github.com/whitequark/prjbureau

## atdh1150usb
ATDH1150USB config + script for OpenOCD
- Original: https://gist.github.com/kellertk/1522c505c9d724cddfc26201cc36fbf0


## Other prerequisites:
- minipro (https://davidgriffith.gitlab.io/minipro/)
- openocd (https://openocd.org/)
- wine (https://www.winehq.org/)
- WinCUPL (https://www.microchip.com/en-us/development-tool/wincupl)
