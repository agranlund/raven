# Misc utils/apps for TOS

|||
|------|----------|
|`cacheoff`|Disable CPU caches|
|`cacheon`|Enable CPU caches|
|`eiffel/`|Eiffel control software|
|`fat32/`|FAT32 filesystem driver for TOS|
|`flash/`|ROM flash utility|
|`fpu_emu`|FPU emulator for 68LC060|
|`fpu_off`|Disable FPU to simulate 68LC060|
|`mon`|Run bootrom debug monitor in terminal|
|`patch_xc`|XControl patcher for 060 compatibility|
|`resetnvm`|Clear nvram|
|`serial.cpx`|Serialport control panel extension|
|`uiptools`|FTP server, requires RTL8019AS network card|
|`ymodem`|Ymodem serial receive program|
