FAT32 filesystem driver for TOS
(c)2026 Anders Granlund
https://github.com/agranlund

This software uses the FatFs library (c)20xx, ChaN
https://elm-chan.org/fsw/ff/

usage:
- just run FAT32.PRG, manually or from the AUTO folder

You should now be able to open and use your FAT32 partitions
from within plain singletasking TOS.

Requires a driver that is compatible with AHDI 3.00 or higher.
(TOS 2.06 or later, EmuTOS, or a third party harddisk driver)
